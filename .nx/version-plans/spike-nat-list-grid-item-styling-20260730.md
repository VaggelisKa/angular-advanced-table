Make each `nat-list` (spike) item a consumer-stylable CSS grid: every field carries `grid-area: <column-id>` and new public tokens `--nat-table-list-gap`, `--nat-table-list-item-areas`, `--nat-table-list-item-columns`, `--nat-table-list-item-gap`, and `--nat-table-list-item-padding` let consumers position each column's field inside the item. The default stacked areas bridge is written via `Renderer2` because Angular host `[style.--*]` bindings silently drop string-valued custom properties on client-side creation. Field labels now render non-string `header` defs (components, templates, or returned text) through `flexRender` with the leaf header context when no static `meta.label`/string header exists, matching the table's cell/header rendering surface; labels sourced from `meta.hiddenHeaderLabel` render screen-reader-only, matching the table's hidden-header contract. `NatList` also gains `enableRowSelection` and `selectionMode` inputs bridged to the shared selection state, marking selected items with `data-selected` (not `aria-selected`, which is invalid on `role="listitem"`) and exposing `--nat-table-list-item-background-selected`. Documented in the theming docs; showcased by the table-to-list gallery group.
