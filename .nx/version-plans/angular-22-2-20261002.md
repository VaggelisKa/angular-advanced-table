Require Angular 22.2: the `@angular/core`, `@angular/common`, `@angular/cdk`, and `@angular/aria` peer ranges are now `^22.2.0`. `<nat-table-toolbar>` follows the reworked `@angular/aria` 22.2 toolbar, which drops widget values and the selection model, so `natToolbarItem` no longer needs or uses an attribute value (`natToolbarItem="export"` still compiles but means nothing), and pointer or Enter/Space interaction on toolbar items is left to the browser.
