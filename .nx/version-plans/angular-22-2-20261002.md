Require Angular 22.2: the `@angular/core`, `@angular/common`, `@angular/cdk`, and `@angular/aria` peer ranges are now `^22.2.0`. `<nat-table-toolbar>` follows the reworked `@angular/aria` 22.2 toolbar, which drops widget values and the selection model, so `natToolbarItem` is now a bare marker attribute: drop any value (`natToolbarItem="export"` still compiles but is ignored, and `[natToolbarItem]` bindings no longer compile), and pointer or Enter/Space interaction on toolbar items is left to the browser. `@angular/cdk` 22.2 also adds `@angular/forms` to its own peers, so apps must provide it.
