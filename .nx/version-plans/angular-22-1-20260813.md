Move the workspace onto Angular 22.1: framework and components to 22.1.1, the CLI packages (`@angular/build`, `@angular/cli`, `@angular/ssr`) to 22.1.3, and `ng-packagr` to 22.1.1.

This clears the only advisory in the graph that was reachable from shipped code: `@angular/platform-server` before 22.0.7 could escape a fallback raw-content serialization. Exposure here was already low, since the showcase builds with `outputMode: "static"` and so runs `platform-server` at prerender time rather than per request, and the package itself is a showcase dependency rather than a library peer or dependency.

The published contract is unchanged. The `peers` catalog stays at `^22.0.2` because the library uses no 22.1 API, and raising a peer floor to match a local toolchain bump would narrow what consumers can install for no benefit. The library's own dependencies (`@tanstack/angular-table`, `tslib`) are untouched.

The `@angular/build>piscina` override is dropped: `@angular/build` 22.1.3 pins `piscina` 5.2.0 itself, so the entry no longer does anything.

`@angular/cdk` and `@angular/aria` stay on 22.1.1 rather than the current 22.1.2, which is still inside the `minimumReleaseAge` quarantine.
