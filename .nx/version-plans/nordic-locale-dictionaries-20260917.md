ng-advanced-table: minor
---

Ship built-in Danish, Swedish, Finnish, and Norwegian Bokmål dictionaries from `ng-advanced-table/locale`. Each language covers all three locale domains and is split by domain like the English copy. Registration is opt-in: `provideNatTableLocales()`, `provideNatTableControlsLocales()`, and `provideNatTableRenderMetricsLocales()` register English on their own, and an application passes the dictionaries it uses — `provideNatTableLocales({ da: NAT_DA_LOCALE_LABELS })` — so it bundles only the languages it ships. `[locale]` on `NatTableSurface` selects a registered id; an unregistered id falls back to English, and a missing table dictionary now warns once per id in development builds. The dictionaries are exported per language and domain (`NAT_DA_LOCALE_LABELS`, `NAT_DA_CONTROLS_LOCALE_LABELS`, `NAT_DA_RENDER_METRICS_LOCALE_LABELS`, and the `NAT_FI_*`/`NAT_NB_*`/`NAT_SV_*` equivalents) together with their locale ids. Locale ids now resolve by RFC 4647 lookup rather than exact match, so a registered `da` also serves `da-DK`; ids that share no subtag, such as `no` alongside `nb`, are still registered separately. Nynorsk is not covered. Each language supplies its own plural and agreement forms rather than the English `+s` rule.
