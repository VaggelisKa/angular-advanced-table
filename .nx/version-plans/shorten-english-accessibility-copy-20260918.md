Shorten the built-in English and Nordic accessibility copy so screen readers repeat less on every header, control, and announcement. A word is dropped only where an ARIA attribute already carries it or an enclosing container has just announced it: menu and pin/move item labels no longer restate the column the menu is named for (`Open column actions for Service column` becomes `Service column actions`, `Pin left: Service column` becomes `Pin left`), the column-visibility chip drops its action hint in favour of `aria-pressed` while keeping the visible state word that SC 2.5.3 requires, the horizontal scroll control drops `table` from its group and button names, and the page-size option aria-label matches its visible text. Sort buttons keep both the `Sort by` affordance and the current sort state — VoiceOver on macOS and TalkBack ignore `aria-sort`, so the name is the only place those users get it — and shed the `Change sorting` suffix and `in ascending order` phrasing (`Sort by Service, sorted ascending, sort 1 of 2`). The grid and list keyboard instructions drop filler without dropping an instruction, and the grid copy still states that a cell whose only content is a button or link focuses it directly, because Enter activates such a control rather than stepping into the cell. The summary and live-region formatters drop leading filler (`Showing`, `are currently`, `across`, `in the … region`) while keeping the nouns that give a context-free announcement its meaning: `visible` still qualifies column and field counts, and column announcements still say `column`. The search announcement now agrees its verb with the row count (`1 row matches "alpha".`). Port the same concise copy to Danish, Swedish, Finnish, and Norwegian Bokmål, preserving localized count forms, Finnish case endings, visible state words, and standalone announcement context. Finnish subset summaries use a count ratio rather than requiring inflection of a formatted total; unfiltered counts use a label followed by the count so singular totals remain grammatical.
